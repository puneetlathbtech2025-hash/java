# Assignment 04 – Wrapper Classes

## Objective
To perform conversion between primitive data types and wrapper objects using Java wrapper classes.

## Exercise 1 – Student Marks
Create a program to convert student marks from String format to Integer and calculate total marks.

**Program:** [StudentMarks.java](StudentMarks.java)

## Exercise 2 – Employee Payroll
Develop an Employee Payroll System that accepts employee IDs, basic salary, and bonus amounts. Convert the entered values into wrapper objects and calculate the net salary.

**Program:** [EmployeePayroll.java](EmployeePayroll.java)

## Concepts
- Wrapper Classes
- Autoboxing
- Unboxing
- Parsing
- Type Conversion
