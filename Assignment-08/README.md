# Assignment 08 – super Keyword

## Objective
To demonstrate the use of the super keyword for accessing parent class members.

## Exercise 1 – Employee and Manager
Create an Employee and Manager program where Manager accesses Employee details using the super keyword.

**Program:** [EmployeeManager.java](EmployeeManager.java)

## Exercise 2 – Vehicle Insurance
Develop a Vehicle Insurance System where child insurance classes access parent vehicle information using the super keyword.

**Program:** [VehicleInsurance.java](VehicleInsurance.java)

## Concepts
- super Keyword
- Inheritance
- Parent Class
- Constructor Chaining
- Method Overriding
