# Assignment 03 – Method Overloading and Static

## Objective
To implement method overloading and use static variables and methods in Java programs.

## Exercise 1 – Calculator
Develop a Calculator program using overloaded methods for addition of integers and decimals. Use a static variable to count calculations.

**Program:** [CalculatorDemo.java](CalculatorDemo.java)

## Exercise 2 – Restaurant Billing
Develop a Restaurant Billing Application where overloaded methods calculate bills for dine-in, takeaway, and delivery orders, while static variables track total orders.

**Program:** [RestaurantBilling.java](RestaurantBilling.java)

## Concepts
- Method Overloading
- Compile-time Polymorphism
- Static Variables
- Static Methods
