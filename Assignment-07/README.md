# Assignment 07 – Inheritance and Interfaces

## Objective
To implement inheritance and interfaces for achieving code reusability and abstraction.

## Exercise 1 – Shape
Create a Shape application where Circle and Rectangle inherit from Shape and calculate area.

**Program:** [ShapeDemo.java](ShapeDemo.java)

## Exercise 2 – E-Commerce Product System
Develop an E-Commerce Product System where electronic, clothing, and grocery products inherit common properties and implement product interfaces.

**Program:** [ECommerceDemo.java](ECommerceDemo.java)

## Concepts
- Inheritance
- Interfaces
- Code Reusability
- Abstraction
- Polymorphism
