# Assignment 10 – Abstract Classes

## Objective
To implement abstraction using abstract classes and abstract methods.

## Exercise 1 – Payment
Create an abstract Payment class and implement Credit Card and UPI payment classes.

**Program:** [Payment.java](Payment.java)

## Exercise 2 – Food Order
Create an abstract FoodOrder class with an abstract calculateBill() method. Implement DineInOrder and TakeAwayOrder subclasses.

**Program:** [FoodOrder.java](FoodOrder.java)

## Concepts
- Abstract Class
- Abstract Method
- Abstraction
